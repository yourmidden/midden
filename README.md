# midden

The issue tracker for [midden](https://yourmidden.app). You'll find the [docs on the site](https://yourmidden.app/docs/). midden's source code isn't in this repository.

Found a bug or have an idea? [Open an issue](../../issues/new/choose). Issues are public, so please leave out anything from your own heap. For anything private, write to [support@yourmidden.app](mailto:support@yourmidden.app).
