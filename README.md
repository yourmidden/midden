# midden

The website, docs and issue tracker for [midden](https://yourmidden.app). midden's source code isn't in this repository.

Found a bug or have an idea? [Open an issue](../../issues/new/choose). Issues are public, so please leave out anything from your own heap.

## This repository

A static site on GitHub Pages, with no build step. `index.html` is the home page, `docs/` the docs, `assets/` everything they use.
